# Data yang Harus Disiapkan: Admin Kabupaten/Kota

**Untuk:** Admin Kabupaten/Kota di bawah Kanwil Kementerian Haji dan Umroh NTB  
**Tujuan:** Agar saat testing live, admin kabupaten sudah punya data lengkap untuk memproses travel di wilayahnya.

> Dokumen ini hanya berisi **daftar data yang perlu kalian siapkan**. Cara input ke sistem akan dijelaskan saat presentasi.

---

## 1. Data Akun Admin Kabupaten

Siapkan 1 orang PIC admin per kabupaten/kota:

| No | Data | Contoh | Wajib |
|----|------|--------|-------|
| 1 | Nama lengkap | Admin Kabupaten Lombok Barat | ✅ |
| 2 | Email aktif | admin.lombokbarat@kemenhaj.go.id | ✅ |
| 3 | Nomor HP (WhatsApp) | 081234567890 | ✅ |
| 4 | Kabupaten/Kota yang diampu | Lombok Barat | ✅ |

> Email dan nomor HP dipakai untuk login. Pastikan **aktif dan bisa diakses**.

---

## 2. Daftar Travel di Wilayah Anda

Kumpulkan data travel **PPIU dan PIHK** yang beroperasi di kabupaten/kota Anda.  
Minimal siapkan **1 travel** untuk testing, idealnya **semua travel aktif** di wilayah.

Per travel, pastikan sudah punya:

| No | Data | Wajib |
|----|------|-------|
| 1 | Nama penyelenggara (sesuai izin) | ✅ |
| 2 | Status (PPIU / PIHK) | ✅ |
| 3 | Alamat kantor | ✅ |
| 4 | Nama pimpinan | ✅ |
| 5 | Nomor telepon | ✅ |
| 6 | Data akreditasi | ✅ |

> Koordinasikan dengan travel agar data perusahaan mereka sudah lengkap sebelum testing.

---

## 3. Data Cabang Travel

Untuk setiap travel di wilayah Anda, siapkan data cabang:

| No | Data | Wajib |
|----|------|-------|
| 1 | Nama travel induk | ✅ |
| 2 | Kabupaten/Kota cabang | ✅ |
| 3 | Nama pimpinan cabang | ✅ |
| 4 | Alamat cabang lengkap | ✅ |
| 5 | Nomor telepon cabang | ✅ |
| 6 | Nomor SK BA | Opsional |
| 7 | Tanggal SK BA | Opsional |

---

## 5. Data Pejabat Penandatangan Sertifikat

Koordinasikan dengan Kanwil, data ini biasanya diinput **sekali** oleh admin Kanwil:

| No | Data | Wajib |
|----|------|-------|
| 1 | Nama lengkap pejabat penandatangan | ✅ |
| 2 | NIP pejabat penandatangan | ✅ |

> Pastikan data pejabat penandatangan sudah disetujui Kanwil sebelum sesi testing sertifikat.

---

## 6. Data untuk Proses Pengunduran Jamaah

Jika ada travel yang akan testing pengunduran, siapkan:

|----|------|-------|

---

## 7. Data Pengaduan (jika ada)

Jika ada pengaduan masyarakat terkait travel di wilayah Anda:

| No | Data | Wajib |
|----|------|-------|
| 1 | Nama pengadu | ✅ |
| 2 | Travel yang diadukan | ✅ |
| 3 | Isi/keterangan aduan | ✅ |

---

## Tugas Admin Kabupaten dalam Alur (gambaran singkat)

Agar paham **data apa yang dibutuhkan**, ini alur kerja admin kabupaten:

1. **Travel** input jamaah → ajukan BA Pemberangkatan
2. **Admin kabupaten** tinjau & setujui BA Pemberangkatan
3. **Admin kabupaten** terbitkan sertifikat PPIU
4. **Admin kabupaten** proses pengunduran jamaah & pengaduan di wilayahnya

> Detail cara kerjanya akan dijelaskan saat presentasi.

---

## Checklist Ringkas: Admin Kabupaten

Centang sebelum datang ke sesi presentasi/testing:

- [ ] Data akun admin sudah siap (nama, email, HP, kabupaten/kota)
- [ ] Daftar travel PPIU/PIHK di wilayah sudah dikumpulkan
- [ ] Data cabang travel sudah lengkap
- [ ] Data sertifikat per travel sudah disiapkan
- [ ] Data pejabat penandatangan sudah dikoordinasikan dengan Kanwil
- [ ] Laptop + koneksi internet untuk sesi testing
